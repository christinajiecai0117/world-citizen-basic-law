# 撰写目标

# Drafting Purpose

本文说明《世界公民基本法》草案 V1.0 的撰写目标。它是对正文的说明，不是条文本身，也不赋予额外法律效力。

## 一、定位

本法旨在确立世界公民的基本权利、义务及其与国家、联合国的关系。世界公民指所有人类个体，不论国籍、民族、种族、性别、年龄、信仰或政治地位。该身份普遍、自动享有，无须申请、授予或许可，不因国籍或其他身份的取得、变更或丧失而终止，也不替代国籍。

本文件是尚未生效的法律草案，供公开共创、审议与后续完善。不得将其表述为已生效法律，也不得将其表述为已经联合国或其他机构通过、批准或授权。

## 二、规范目标

1. **可执行的权利与义务。** 条文应写明谁享有权利或承担义务、内容是什么、在何种条件下适用或受到限制。一则条文尽可能只规定一项规则。避免空洞的强语气或无法实施的口号。
2. **完整的权利集群。** 覆盖生命与人身完整、自由与人格、平等与非歧视、政治权利、经济与经营、社会与文化、教育、婚姻与家庭，以及和平与安全；并规定世界公民的义务，以及实施、救济与责任。
3. **防范政治迫害。** 禁止因政治意见、信仰、和平表达、政党或其他政治组织归属、竞选或担任公职，或因支持、资助、雇佣或与特定政治人物、组织有关联，而实施或促使实施调查、检控、审判、处罚、监管、许可、税收、采购、财产或资格限制、民事追责等不利措施。禁止选择性执法和滥用法权。公职、候选资格、社会影响、企业经营或发表不受欢迎的政治意见，不降低法律保护。为制止正在实施的政治迫害，可在用尽国内救济前请求必要的国际临时保护。禁止政治迫害属于不得克减的核心权利。条文不针对任何国家、政党或个人。
4. **武器与战争追责。** 因武器使用，或因战争、武装冲突或生物战而受害的世界公民及其家属，有权向提供方、运输方、发射方、实施方及其主要负责人追责。主要负责人依行为认定，包括但不限于对上述行为起决定、命令、组织、控制或推动作用的国家元首、国防或军事主管部门负责人、武器生产与运输单位负责人，以及推动战争、武装冲突或与宗教相关武装冲突的宗教领袖。责任为无限连带责任，包括民事赔偿、刑事责任与国际制裁，不受主权豁免限制，亦不因动机、职务、政治、宗教理由或离职而免除。生物武器与毒素武器适用更具体的专章规则；与一般规则不一致时，以对受害人及其家属保护更充分者为准。
5. **与现行公开文书可核验地对齐。** 对照《世界人权宣言》《联合国宪章》和《禁止生物武器公约》的现行官方或公共领域文本，补全缺漏并处理明显张力。开放教材和汇编仅作框架参考，不大量摘录，也不把未核验的渊源写进正文。与国际人权条约冲突时，以对个人保护更充分者为准；与宪章义务冲突时，以宪章义务为准。不得将本法解释为授权破坏宪章宗旨与原则，或授权摧毁本法所载权利。
6. **克制的机构条款。** 不虚构新的国际机关，也不自行扩大联合国人权机制、国际法院或国际刑事法院等机构的现有职权。和平解决争端不新设法庭。刑事责任的追究适用公正审判、无罪推定与辩护权。

## 三、起草方法

- 正文与评注分离；评注不得写进条文，装作具有拘束力。
- 每项修订包含：条文号、旧文、新文、简要理由。理由可以准确引用已核验的公开文书，不得编造判例、条约或机构授权。
- 已公开或已进入流通的序列，插入新条时使用扩展编号，并保持原序号稳定。
- 中文与英文表述同一规则；发现不一致时，应一并修正，不得使一种文本暗中改变另一种文本的含义。
- 平行草稿（包括其他撰稿人或工具产生的文本）必须收口为同一份正文。已合并到本仓库默认分支的文本是唯一准据。
- 未定稿不擅自对外发布。

## 四、本版已作的政策选择

下列选择已写入 V1.0 正文；若需更改，应通过议题和拉取请求修订，并更新修订说明与版本记录。

- 第24-1条含与《联合国宪章》保持一致的有限除外：仅适用于符合宪章的单独或集体自卫，或安全理事会依宪章授权的强制行动中对非生物、非毒素武器的使用；不适用于非法使用武力或侵略、生物或毒素武器、政治迫害或其他明文禁止的行为，也不免除超出必要限度的责任。
- 第12条、第144条对通过形式采用双轨表述：作为宣言通过时，是各国力求实现的共同标准，并须另经条约或其他国际协定落实；作为多边条约通过时，对同意受拘束的国家，自达到随后议定书规定的条件之日起生效。
- 父母依第101条行使权利时，以儿童最大利益为优先考虑；与第102条冲突时，以儿童最大利益为准。
- 第97条保留男女有权结婚并成立家庭的表述，并写明本法不妨碍依法承认婚姻以外的家庭或伴侣关系；未在本版将婚姻定义本身扩大。
- 第84条不编造完整的最低核心清单；核心义务至少包括实现社会权利时的非歧视，以及无正当理由不得倒退剥夺本法已承认的基本生活条件。
