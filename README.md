# 《世界公民基本法》草案 V1.0

**Draft Basic Law of World Citizens, Version 1.0**

世界公民基本法正式文本与全球共创仓库。

本拉取请求将《世界公民基本法》草案 V1.0 完整文档存入本仓库。本仓库存放该项目的正式工作文本，供全球共创。V1.0 是供公开共创使用的完整工作草案，**不是已生效法律**，也尚未经联合国或其他机构通过。此处“正式文本”指：合并到默认分支的措辞，是本项目的唯一事实来源。

默认分支中的正文是唯一准据。任何平行草稿、评注、译文或对外口径，均须与已合并文本核对，不得另行形成第二份正文。

## 撰写目标

1. 确立世界公民作为所有人类个体普遍、自动享有的法律地位，及其基本权利与义务，并明确与国家、联合国的关系。世界公民身份不替代国籍，也不因国籍变动而终止。
2. 将生命与人身完整、自由与人格、平等与非歧视、政治权利、经济与经营、社会与文化、教育、婚姻与家庭等权利，写成可执行的条文：写明权利或义务的主体、内容、条件和限制，避免无法实施的口号。
3. 防止以公权力实施的政治迫害，包括选择性执法和滥用法权。不因政治意见、信仰、和平表达、政党归属、竞选或担任公职、企业经营，或与特定政治人物、组织有关联，而降低法律保护。条文本身不针对任何国家、政党或个人，对所有世界公民一体适用。
4. 确立因武器使用，或因战争、武装冲突或生物战而患病、受伤、死亡或遭受严重损害的世界公民及其家属，向武器提供方、运输方、发射方、实施方及其主要负责人追责并获得有效救济的权利。该项责任包括民事赔偿、刑事责任与国际制裁，不因任职或离职而免除。
5. 禁止侵略战争与非法使用武力，禁止生物武器与毒素武器，并以和平方法解决国际争端。本法不得被解释为授权破坏《联合国宪章》的宗旨与原则。
6. 与《世界人权宣言》《联合国宪章》及《禁止生物武器公约》作可核验的对照，补全缺漏并消除明显张力；与国际人权条约冲突时，以对个人保护更充分者为准。不虚构未经核验的条约依据或机构职权。
7. 保持正文与评注分离；修订须附条文号、旧文、新文和简要理由。插入新条使用扩展编号，不在已发布序列上擅自重编号。
8. 文本为尚未生效的法律草案，供公开共创、审议与后续完善。其法律效力取决于日后通过时所采取的形式；仅经提议或公开，并不当然产生条约义务，也不自行扩大国际机构的现有职权。

更完整的说明见 [docs/PURPOSE.md](docs/PURPOSE.md)。

## 协作方式

详细规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。要点如下：

- **单一事实来源：** 默认分支只存放已确认的工作正文及相关正式文件。修改在分支或分叉上进行，经拉取请求进入默认分支。
- **一议题一建议：** 用议题提出修改，说明理由，并尽可能附上拟议条文。
- **拉取请求须关联议题或写明目的：** 不得在同一文件中把正文、评注和译文混在一起而不加标注。涉及条文或定义的修改，合并前须做一致性审查。
- **未经确认不得合并：** 默认分支的合并须经项目发起人或其指定的维护者确认。平行来源的草稿须收口为同一份正文，避免出现两份正文。
- **合并后更新日志：** 记入日期、版本或拉取请求编号，以及一句话摘要。
- **编号稳定：** 不重编已有条文序号；插入用扩展编号（如第12-1条）。
- **不擅自对外发布未定稿：** 对外展示、翻译发布或官方口径，一律以默认分支已合并文本为准。

参与本仓库即须遵守 [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) 和 [TERMS.md](TERMS.md)。公开发布所用许可尚待项目发起人确认，上传前请在 `TERMS.md` 中补全。
